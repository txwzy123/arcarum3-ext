# arcarum3-ext

《碧蓝幻想》转世沙盒辅助工具，包含实时地图 Chrome 扩展、路径规划和导本/事件记录功能。

## 已实现功能

### Chrome 扩展

- 拦截游戏页面的 `fetch` 和 `XHR` 请求。
- 自动识别沙盒地图接口和移动后的状态更新。
- 读取地图节点、节点类型、坐标、相邻节点、当前位置、访问状态和瘴气状态。
- 侧边栏显示当前地图状态和节点数量。
- 独立地图窗口显示完整地图，不受游戏窗口大小限制。
- 使用游戏地图底图和官方节点图标绘制地图。
- 支持地图拖拽平移、滚轮缩放、整图适配和缩放按钮。
- 点击节点显示节点类型、事件类型、瘴气状态和玩法说明。
- 显示当前位置、已访问节点、可移动节点、任务节点和瘴气区域。
- 地图图例可以筛选并高亮指定类型的节点。
- 游戏移动节点或瘴气范围变化后，地图窗口自动刷新。

### 路径规划

- 计算两个节点之间的最短路线。
- 从当前位置规划到最近的宝箱、回复点、商店等目标。
- 支持“最短”“收益”和“安全”等路线策略。
- 根据节点类型、已访问状态、收益和瘴气区域计算路线评分。
- 支持限制最大移动点数。
- 瘴气范围会影响路线评分，但不会在没有其他路线时强制阻止移动。
- 支持粘性重规划：移动一步后，在路线仍然合理时尽量沿用原路线。

### 导本和事件数据库

- 记录游戏接口中出现的导本效果。
- 区分当前持有导本、历史收录导本和当前事件候选。
- 支持中文、日文和英文文本。
- 支持按稀有度筛选和关键词搜索。
- 记录导本来源、图标类型、首次发现时间和最后发现时间。
- 记录事件场景、选项、结果、选择 ID 和回合消耗。
- 支持普通事件和特殊事件。
- 支持导出导本数据库和事件数据库 JSON。
- 支持合并多个玩家导出的数据库，并生成冲突报告。

### 离线分析工具

- `tools/analyze_har.py`：从 HAR 中筛选和排序疑似地图接口，并导出 JSON。
- `tools/diff_har.py`：比较两次抓包，查找地图初始化或移动后的状态变化。
- `tools/map_viewer.py`：离线查看地图 JSON。
- `tools/pathfind.py`：从地图 JSON 计算路线和地图摘要。
- `tools/merge_guidebook_databases.mjs`：合并导本数据库。
- `tools/merge_event_databases.mjs`：合并事件数据库。

## 安装扩展

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择仓库中的 `arcarum3-ext/` 目录。
5. 打开碧蓝幻想并进入转世沙盒地图。

详细说明见 [`arcarum3-ext/README.md`](arcarum3-ext/README.md)。

## 已识别接口

地图数据接口：

```text
GET /arcarum3/dungeon/content/index/0
```

主要数据：

- `option.dungeon.node_list`
- `option.dungeon.current_node_id`
- `option.dungeon.node_icon_info`

移动接口：

```text
POST /rest/arcarum3/dungeon/move_node
```

## 安全说明

- 抓包文件可能包含 Cookie、token、用户 ID 和账号状态，不应上传。
- `.gitignore` 会排除 `captures/`、`out/` 和本地工作目录。
- 扩展数据默认保存在浏览器本地 `chrome.storage.local`。
- 工具只做接口观察、离线分析和路线计算，不自动执行战斗或操作账号。
